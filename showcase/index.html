02The fix is structural — flip the architecture

v1 relied on discipline ("please append-only, please don't fight over files"). Discipline doesn't survive 5 concurrent writers. v2 makes shared-file conflicts impossible by construction: every shared write is either a new file or your own file.

CONFLICT ×3 · 34/45 commits · 9 merge-noise
0 conflicts · by construction

06Boot it — the whole protocol is four lines

  
Every session starts with one sentence. That's the entire onboarding.

  
git clone … && cd repo && .\scripts\setup.ps1

  
I am <name>, <role>. Follow AGENTS.md.

  
You are the orchestrator. Follow docs/ORCHESTRATOR.md.

  
scripts/sync

  
The orchestrator is the cheapest session by design
  (headlines + git diffs, ~2–4k tokens per refresh) — its real requirement is uptime, not credits. If it dies,
  anyone boots a new one with line 3. Nothing is lost: the board is a cache.
